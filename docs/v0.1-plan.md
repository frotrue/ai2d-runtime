## v0.1 hypotheses

- H1: a compact versioned ScenarioSpec expresses static, moving, and texture-switching sprite workloads without scenario-specific gameplay C++.
- H2: generational handles + dense storage + preallocated extraction + CPU culling + instanced batching scale in measurable, explainable phases.
- H3: after load/reserve/warm-up, the measured project hot path has zero tracked C++ heap allocations, frame-arena overflows, and capacity-growth events.
- H4: invalid input/resources and platform/performance failures are separated by stable diagnostic codes and structured context.
- H5: a same-fingerprint baseline comparator uses robust dispersion and absolute floors to separate noise from regression.

## Architecture boundary

The concrete modules are `foundation`, `world`, `platform_sdl`, `renderer2d`, `scenario`, and `runtime`. `foundation` has value types, diagnostics/results, JSON writing, timers/statistics, frame arena, and allocation counters. `world` has only fixed components, generational entity state, dense storage/query, and mutation guards. `scenario` alone parses JSON and produces a numeric sequential `ExecutionPlan`. `renderer2d` consumes extracted items, owns all Vulkan/VMA resources, and performs culling/queue/batching/instance submission. `platform_sdl` owns the window/events. `runtime` orchestrates public APIs without reaching into private storage.

Raw Vulkan C API plus narrow move-only renderer-specific wrappers is selected; there is no Vulkan-Hpp dual path and no RHI. Renderer ordering is ascending layer, then texture within a layer; strict same-layer alpha order is intentionally not guaranteed. The first upload strategy is a persistently mapped per-frame instance buffer, revisited only if measured evidence warrants it.

## Resolved blockers and remaining risks

- Validation layers were initially absent; portable SDK bootstrap and wrapper-provided `VK_LAYER_PATH` resolved this blocker.
- `slangc` and `spirv-val` were initially absent; verified standalone Slang plus the portable SDK resolved this blocker.
- Visual Studio compiler environment variables are not inherited by the shell. `engine.py` now captures `VsDevCmd.bat`, normalizes Windows' case-insensitive `Path`, and exposes SDK resource tools to Ninja.
- The Parsec virtual display and OBS Vulkan layer may affect presented smoke; offscreen benchmarks are the primary performance path and fingerprints record active environment.
- Windows MSVC supports ASan but not the requested UBSan equivalent; UBSan will be reported UNAVAILABLE on this host.

Generic/archetype ECS; runtime components/reflection; plugin/API ABI; scripting/VM/expression/visual scripting; full or persistent Game IR; optimizer/codegen/scheduler; multithreading/jobs; spatial structures; collision/physics; animation/tilemaps/particles/audio/UI/editor; asset hot reload/decoders/general pipeline/atlas compiler; bindless/descriptor-indexing architecture; GPU-driven/compute/indirect rendering; generic RHI/render graph/materials/post effects/lighting; networking/3D/mobile/console/web; automatic device-loss recovery; speculative factories/registries/interfaces.
