# ADR-0001: v0.1 hypotheses and boundary

- Status: accepted
- Date: 2026-08-12

## Context

The experiment needs evidence about declarative authoring, dense execution, measured hot-path memory, structured failures, and benchmark comparability—not a general engine feature set.

## Decision

Implement only the five hypotheses in `docs/v0.1-plan.md`, three fixed components, two built-in operations, three sprite workloads, one 2D pipeline, sequential execution, and the stated validation/benchmark harness. The explicit anti-goal list is binding.

## Alternatives considered

A generic ECS/RHI, scripting layer, full compiler IR, and jobs were rejected because no v0.1 workload supplies evidence for their cost.

## Evidence and consequences

The repository started empty, so there is no compatibility constraint forcing broader abstractions. This keeps every subsystem measurable but deliberately limits game expressiveness.

## Revisit trigger

A required workload cannot be represented without arbitrary C++, or a correctness contract cannot be met within this boundary.
