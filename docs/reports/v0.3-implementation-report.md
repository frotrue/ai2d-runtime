# v0.3 implementation report

- Status: complete; fresh-AI and ChatGPT Pro release gates passed
- Evidence date: 2026-08-13 (Asia/Seoul)
- Runtime version: `0.3.0`
- Compatibility reference: Breakout GameManifest/SceneSpec 0.2
- Validation games: `samples/snake/game.json` and `samples/grid_collector/game.json`

## Executive summary

v0.3 implements a bounded, ordered Event–Condition–Action runtime rather than a Snake-specific extension. Versioned 0.3 manifests compile logical grids, numeric event dispatch, typed conditions/actions, exact fixed-tick grid motion, transform-chain followers, prefix activation, and deterministic unoccupied-cell relocation into a validated `GamePlan`. Every runtime range, occupancy buffer, dispatch list, snapshot, and system-state array is allocated before measured fixed-tick execution.

The proof content is a complete declarative Snake and a materially different Grid Collector. Neither sample contains game-specific C or C++. The original 0.2 Breakout remains accepted without edits, and its source/plan hashes remain pinned at `9083610792174461301` and `6721347758608948258`.

The native Windows player, statically linked SDL/MSVC runtime, embedded SPIR-V, exact dependency inspection, deterministic ZIP writer, bounded input scripts, and official `package` command make these games distributable without the build tree. The Vulkan loader and a Vulkan 1.3-capable driver/GPU remain system requirements.

## Declarative sample evidence

### Snake

- Cardinal motion advances exactly one cell on an 8×8 board every six fixed ticks and rejects direct reversal.
- Food collision increments score/length, activates the next tail reserve, and relocates food deterministically outside occupied cells.
- All 63 followers, including inactive reserves, track predecessor history after collision simulation.
- Deterministic scripts cover reverse rejection, growth, self collision, lose, session restart, and a Hamiltonian full-board run.
- The full-board run ends in `win` with `score=610`, `length=63`, `food_available=0`, 61 successful relocations, and food deactivation when no cell remains.

### Grid Collector

- Reuses grid motion, ordered collision rules, deterministic relocation, integer state, and prefix group activation without transform-chain following.
- Its checked-in script collects five gems while hazards activate from zero through five, reaches `win`, then restarts into a reset game session.
- The winning state is `score=5`, `hazard_count=5`, `alive=1`; after restart it returns to `game` with reset state before deterministic play resumes.

## Known limitations

- The complete evidence is from one Windows/MSVC/NVIDIA host. Other platforms, compilers, GPU vendors, and drivers are unverified.
- Collision remains deterministic bounded axis-aligned gameplay collision, not general rigid-body physics. Rotation, friction, mass, constraints, and dynamic-versus-dynamic rules are unsupported.
- Runtime text uses a prebuilt atlas and explicit glyph coverage; there is no shaping, fallback, localization framework, or runtime font rasterizer.
- Content remains adjacent to the EXE by design. There is no single-file content embedding, hot reload, save-game serialization, editor, arbitrary scripting, or runtime component registration.
- Vulkan device loss remains a terminal structured failure; automatic device-loss recovery is outside v0.3.

Both independent release gates are complete, every confirmed review defect is fixed, and the post-review validation/package matrix passes.
