# v0.2 implementation report

- Status: complete on the Windows reference host
- Evidence date: 2026-08-12 (Asia/Seoul)
- Runtime version: `0.2.0`
- Validation game: `samples/breakout/game.json`

## Executive summary

v0.2 implements the approved bounded engine-feature slice. A versioned GameManifest plus SceneSpec compiles to a validated numeric `GamePlan`, then executes through fixed-step scenes without game-specific C++. The slice adds action edges, continuous AABB collision and reactions, PNG/font/WAV assets, a bounded audio mixer, virtual-resolution UI, scene transitions with reset-or-retain semantics, persistent FPS settings, and the fully declarative Breakout sample.

This remains an AI-first closed runtime rather than a general-purpose engine. Animation graphs, editor tooling, scripting/plugins, general rigid-body physics, hot reload, and a generic asset pipeline are deliberately outside v0.2. The original ScenarioSpec 0.1 compiler/runtime and its hash contract remain available.

All available final gates pass: fresh Debug and Release builds, 76/76 Debug tests, 76/76 Release tests, 76/76 optimized benchmark-preset tests, 76/76 MSVC AddressSanitizer tests, 76/76 standard plus synchronization Vulkan Validation tests, 56/56 GPU-disabled tests, the 73-file architecture check, and the complete quick benchmark sweep. The Catch2 executable reports 1,370 assertions in 53 unit cases. The benchmark artifact contains 32/32 passing 1K/10K/50K/100K results with zero measured project C++ heap allocations and zero capacity-growth events. UBSan remains unavailable under the reference MSVC toolchain and is not represented as passing.

## Independent GPT Pro review

The complete review-ready project was packaged as 134 entries (985,938 uncompressed bytes) and submitted to an authenticated ChatGPT Pro session. The uploaded ZIP SHA-256 was `9044d61d16d8083ec5ef1fc9ea31be45680b9d4fb1ec0506d60f3dfc7bffae6c`. GPT Pro completed its response after 78 minutes 37 seconds; work did not proceed on partial output. The private review session is intentionally not linked from this public repository.

GPT Pro reported eight High and four Medium findings. Every item was checked against the live workspace; all twelve were confirmed and remediated rather than accepted blindly.

| ID | Severity | Confirmed issue | Implemented remediation and regression evidence |
|---|---|---|---|
| F-001 | High | Mutable `GamePlan` revalidation was incomplete and hashing trusted `key_count` | Central bounds/constants, complete enum/index/path/numeric/capacity checks, safe bounded hashing, runtime exception boundary, and adversarial plan mutations |
| F-002 | High | Public collision `reaction_count` could index past the fixed reaction array | Validate count, groups, reaction and target enums before clearing scratch data or touching World; malformed-boundary tests |
| F-003 | High | Zero-tick edges could be lost, catch-up ticks could replay edges, and SDL polling could miss a quick tap | SDL event-edge capture plus keyboard-level reconciliation; pending tick-edge latch consumed after the first tick; zero/one/three-tick regression test |
| F-004 | High | Candidate generation could miss reflected paths and a trigger could suppress a later blocker | Re-query grid cells for each remaining reflected segment, store ignored logical pair keys, and continue after nonblocking contact; corridor, trigger-then-wall, and kinematic speed-transfer tests |
| F-005 | High | Kinematic motion and reflection used the wrong time/velocity, while separating touching contacts could reflect | Derive kinematic velocity from previous/current transforms, sweep both bodies at elapsed time, reflect relative velocity only when approaching, and separate penetration; dedicated tests |
| F-006 | High | UI formatting allocated/growed per frame and plans could exceed renderer capacity | Compile placeholder tokens once, use transparent lookup and `to_chars`, reserve worst-case bytes/submissions, validate exact 100,000 boundary, and measure zero allocations after warm-up |
| F-007 | High | PNG/WAV limits were enforced after SDL allocations and graphics could initialize before asset failure | Source/header/dimension/frame/converted-size preflight, stricter WAV structural consistency, post-decode defense, exception diagnostics, and decode all CPU assets before window/renderer/audio setup |
| F-008 | High | Presented Vulkan failures after image acquire but before submit could poison semaphore/image state | Track acquisition and shut the renderer down on any unsafe pre-submit, reset-fence, submit, acquire, fence, flush, or unexpected present failure; presented reset/begin/end fault tests |
| F-009 | Medium | Missing settings overwrote the manifest default, schema parsing was substring-based, and writers shared a temporary name | Missing file returns no value, bounded exact JSON parser, unique PID/counter temporary names, local writer mutex, transient Windows replacement retry, atomic last-writer-wins file replacement, and concurrent-writer test |
| F-010 | Medium | `reset_scene` was parsed but ignored | Preallocated per-scene snapshots retain transforms, velocities, sprite/collider state, active flags and UI focus; reset and retained re-entry checks use deterministic scene-state checksums |
| F-011 | Medium | Game CLI errors violated the common envelope/exit contract and non-interactive `frames=0` could run forever | Stable build/environment/diagnostics/metrics/artifacts envelope, diagnostic exit mapping, and positive frame requirement for headless/offscreen runs, including GPU-unavailable coverage |

The associated cross-cutting risks were also closed: collision capacity is checked after logical pair deduplication, event storage is reserved for the collider/impact bound, transition state resets occur only after a successful destination load, and settings/runtime standard-library failures are converted to diagnostics at public boundaries.

## Known limitations and next boundary

- Evidence comes from one Windows/MSVC/NVIDIA host. Linux, macOS, other GPU vendors, and lower-end devices are unverified.
- UBSan is unavailable. ASan passes, but this does not provide equivalent undefined-behavior coverage.
- Collision is deterministic bounded AABB gameplay collision, not general physics. Dynamic-versus-dynamic rules, rotation, friction, mass, constraints, and arbitrary shapes are unsupported.
- Scene retention is in-memory runtime state, not a save-game serialization framework.
- PNG and WAV loading is startup-only; there is no hot reload, streaming, transcoding pipeline, or user-extensible importer.
- Text uses prebuilt atlas metadata and static glyph coverage. There is no shaping, fallback-font system, or general localization pipeline.
- Device loss is terminal and structured; automatic device-loss recovery remains out of scope.
- Animation and editor tooling should be separate future experiments only after a concrete declarative workload establishes their authoring and runtime contracts.

The next coherent experiment is a small declarative sprite-animation operation with bounded clips, numeric frame ranges, deterministic fixed-tick playback, atlas reuse, and allocation-free extraction. An editor should not precede that runtime contract; it would otherwise encode unstable semantics into tooling.
